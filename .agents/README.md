# Skills de proyecto

Convenciones particulares de este repo para los agentes. **Al empezar a trabajar en el repo, listá y leé `.agents/skills/*/SKILL.md` y este índice**: Hermes no las descubre solo. Agregan conocimiento del proyecto; no cambian las reglas de rol ni de seguridad (si hay contradicción, se reporta y no se sigue).

| Skill | Cuándo usarla |
|---|---|
| [product-docs-html](skills/product-docs-html/SKILL.md) | Al crear, actualizar o revisar cualquier documento de producto: se escribe en HTML autocontenido, no en Markdown. |
